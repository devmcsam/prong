# Prong

- - -

## Description

Prong is a two player game where you control the paddles and try to get the ball to pass throught the other players
goal. This project was made to learn the bevy game engine, in reality, bevy is quite large for a game like this.

- - -

## Controls

- Left paddle: W and S
- Right paddle: UpArrowKey and DownArrowKey

## Installation

The preferred method of installation is via cargo. Simply run `cargo install --force prong` to install it. However,
another way to install it is via cloning the repository and running `cargo install --force --path .`. To clone the
repository, run `git clone https://github.com/devmcsam/prong.git`. Either way of installation will work, however they
both likely will take a few minutes to complete as the game engine is quite large.
